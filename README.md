# Gisa Ferreira

Site institucional estático com serviços, links para livros e contato. O formulário compõe uma mensagem e abre o WhatsApp (11) 99873-6555, já documentado no código. A pessoa ainda precisa enviar a mensagem no WhatsApp.

O assistente usa respostas fixas. Não existe pagamento ou entrega de livros digitais neste repositório.

Executar localmente: `python -m http.server 8000`.

Verificar a jornada: `node --test evals/journey.test.mjs`.

A imagem Docker usa nginx na porta 8080. Validar o atendimento e os links externos antes de considerar a jornada comercial concluída.
